# 🏘️ Mahalleli Platform

A role-based community aid and decentralized resource management platform designed to connect municipalities, local merchants, donors, and beneficiaries into a transparent logistics ecosystem.

---

## 🌟 Key Features

- **Role-Based Workflows (RBAC):** Tailored interfaces and permissions for four core stakeholders:
  - **Municipality (Belediye):** Verification workflows, citizen eligibility approval, and distribution oversight.
  - **Local Merchants (Esnaf):** Real-time inventory tracking, quota management, and aid order fulfillment.
  - **Donors (Bağışçı):** Transparent pool funding and item-specific donation packages.
  - **Beneficiaries (İhtiyaç Sahibi):** Direct item selection, order scheduling, and pickup/courier options.
- **Localized Aid Logistics:** Decentralizes aid distribution by routing orders directly through neighborhood shops rather than central warehouses.
- **Secure Architecture:** Authentication, session management, and relational data flows powered by modern backend services.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS
- **Backend & Database:** Supabase (PostgreSQL, Auth, Real-time APIs)
- **State & Routing:** Context API, Custom Hooks
- **Tooling:** pnpm / npm
