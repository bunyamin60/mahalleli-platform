# 🏘️ Mahalleli Platform

> **Role-Based Community Aid & Decentralized Resource Logistics Platform**

Mahalleli is an end-to-end community support platform designed to connect municipalities, local neighborhood merchants, donors, and beneficiaries into a transparent, decentralized aid ecosystem.

---

## 🎯 Core Concept & Mission

Traditional aid systems often rely on centralized logistics and fixed food parcels. **Mahalleli** decentralizes this process:
- Donations are pooled transparently.
- Beneficiaries order the exact goods they need.
- Orders are fulfilled directly by registered local neighborhood shops (esnaf), supporting both local micro-economies and dignified aid distribution.

---

## 👥 Multi-Role Ecosystem & Workflows

The platform features tailored interfaces and permissions (RBAC) across four core user archetypes:

- **🏛️ Municipality (Belediye):** Verification of citizen eligibility, dynamic quota allocation, and city-wide distribution tracking.
- **🏪 Local Merchants (Esnaf):** Real-time inventory status, incoming aid ticket processing, and decentralized order fulfillment.
- **🤝 Donors (Bağışçı):** Direct pool funding, targeted category assistance, and transparent impact tracking.
- **📦 Beneficiaries (İhtiyaç Sahibi):** Direct item selection, order scheduling, and dignity-first pickup/delivery management.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** React 18, Vite, Tailwind CSS
- **Backend & Database:** Supabase (PostgreSQL, Row-Level Security, Auth)
- **State & Data Management:** React Context API, Custom Hooks, Async Service Layer
- **Architecture:** Modular component design, role-based routing, responsive layout
